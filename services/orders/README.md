# Orders Microservice

Мікросервіс управління замовленнями з міжсервісною REST-комунікацією з Users та Products.

## Ендпоінти
- `GET /health` — перевірка працездатності
- `GET /ready` — перевірка з'єднання з БД
- `GET /api/v1/orders` — список замовлень (з фільтрацією за user_id або status)
- `POST /api/v1/orders` — створення замовлення (з автоматичною перевіркою юзера та резервуванням товару)
- `GET /api/v1/orders/{id}` — отримання замовлення (збагаченого даними юзера та товару)
- `PUT /api/v1/orders/{id}` — оновлення статусу або кількості
- `DELETE /api/v1/orders/{id}` — скасування/видалення замовлення з поверненням товару на склад
