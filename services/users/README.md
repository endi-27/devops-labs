# Users Microservice

Мікросервіс управління користувачами для навчальної платформи з курсу DevOps.

## Ендпоінти
- `GET /health` — перевірка працездатності
- `GET /ready` — перевірка з'єднання з БД
- `GET /api/v1/users` — список користувачів
- `POST /api/v1/users` — створення користувача
- `GET /api/v1/users/{id}` — отримання користувача за ID
- `PUT /api/v1/users/{id}` — оновлення користувача
- `DELETE /api/v1/users/{id}` — видалення користувача
